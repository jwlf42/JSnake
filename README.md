# JSnake

JSnake is a Snake game written in C using Simple Draw.

The project focuses on a clean separation of game logic,
animation, and rendering.

## Project History

Early development milestones created before Git was used
are archived in [`legacy_pre_git/`](legacy_pre_git).

## Requirements

This project depends on **Simple Draw**, a lightweight graphics
library used for rendering.

Simple Draw can be obtained here:
https://www.thm.de/iem/martin-graefe/tools-fuer-den-einstieg-in-die-programmierung

Simple Draw was created by Prof. Dr. Martin Gräfe (THM)
and is used for educational purposes.
